# 视觉语言与对齐

用于整套风格定义、参考迁移、封面设计及全局元素精修。

## 从真实参考中提取设计规则

先看封面、典型内容页、密集证据页和结尾。记录背景明度、主色和强调色、文字与图片面积关系、标题高度、导航位置、蒙版方向、照片裁框与图注间距。仅凭文字提取无法判断这些关系。

参考的功能不同：模板决定应保留的结构，风格参考提供视觉方向，事实素材提供证据。不要把三者混为一谈。若允许重设计，可调整导航位置；若明确保留母版，则保留其各元素及层级，不用近似重画替代。

## 配色、字体、标志

- 无指定风格时以华文楷体和浙大蓝 `#074591` 为起点，正文采用清晰深色。低饱和配色服务于协调，不牺牲对比度。
- 红金、蓝白、浅色多板块等都可以是有效方案；章节共享明度、色彩逻辑及组件风格，避免某页独立换色。
- 正文、同级标题、同类图注分别有统一字号和字重；不要为了长图注单页随机缩字。标题尽量加粗强化层级，但不是全页所有内容加粗。
- 用户指定英文、数字或页码同用华文楷体时一致执行；否则沿用可读的模板或专业规范。原始截图里的任何字体不受PPT正文规范影响。
- 书法主标题如采用“方正字迹-心海龙体 简繁”，先检查字体可用与许可；不随公共 Skill 分发字体文件。替代方案须保持气质和实际可读性，不能静默替换后宣称一致。
- 校标用用户提供的正规矢量或透明图，保持纵横比与规范颜色。不要生成或凭观感重画，也不要带上截图白底/色块。深浅背景需要匹配的正规版本，不任意改校标颜色。封面与内页同标可统一视觉尺度。

## 封面与封底

真实全幅场景照片可以与单色/渐变蒙版叠加。蒙版保护标题对比度，让主体仍可辨；横向、侧向或局部曲线的选择服从主体位置和参考，不固定方向、不遮掉关键人物。

主标题与副标题、答辩人、日期构成明显层级。封尾呼应可复用标题几何、色彩和照片语言，不一定复制相同信息。

两行书写大字可拆为单字或词组进行有节奏的错落：

1. 先保持同一横向字距体系与充分行间留白。
2. 再按用户指定或参考设计安排局部顶齐、底齐和高低关系。
3. 观察真实笔画边界与视觉重心，调整字框坐标；字框上沿相同不等于笔画齐平。
4. 比较两行的气口、密度和整体平衡；避免随机跳字、挤压或碰撞。
5. 封面、封底同步应用已确认的对齐规则。

不要把某次十字标题、标点替换、字号或坐标变成下次封面的硬标准。

## 网格与分组

先确定内容区边界，再分栏；导航和校标占用空间必须计入。相关对象成组检查，例如将三组数字和说明作为一个块，比较这个块与导航、右图的距离。

对需均匀分布的图组，可用以下几何关系辅助（单位一致）：

```text
列宽 = (内容区宽度 - (列数 - 1) × 列间距) / 列数
同组中心 = left + width / 2
顶部留白 = 组图顶部 - 上方文字块底部
底部留白 = 下方文字块顶部 - 组图底部
```

这些关系用于诊断，不替代视觉判断。文本框自带边距、字形留白、阴影与不规则图片都会影响实际观感。

- 对称列比较视口宽高、间距、标题位置和视觉重量，不仅比较图片文件的像素尺寸。
- 图注靠近所属图片，组间距应明显大于图注间距；换行后仍与图片同中心。
- 数字摘要可与表格/图片边缘对应，避免悬浮在无关位置。
- 色块给予足够内边距；不让文字或数字挤压色块上下边缘。
- 阴影可采用一致、克制的外部阴影帮助区分照片与背景；不遮字、不混用多种厚边框或强阴影。

## 导航、编号、页码

如保留侧栏，项目名尽量一行完整显示、共同水平中心、均匀纵向分布；当前栏目与高亮色块垂直居中。与上方校标的中心关系按模板/用户要求统一。顶栏同样遵循明确的分组和当前板块提示。

当前需要分节编号时，可采用“1.1  主题：主旨”，编号与正文的空格数量全局一致；独立单章可采用“2  主题：主旨”。并非所有演示都需要数字章节。合并或删除页面后同步重编，不保留无意义的旧序号。

页码的字体、字重、格式和右边界统一，可对齐右上标志的右边界。不要为迁就某一页内容单独移动全局元素。
