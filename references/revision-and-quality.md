# 修订与验收

用于续改、脱敏、导出检查，以及带音视频演示的专项核验。

## 版本与修改边界

确认用户最新提供或认可的文件；文件名“终稿”、旧缩略图、上轮完成声明不能替代实读。必要时记录修改时间或哈希。原始素材和用户未授权改写的文件保持只读，在项目既有成果目录操作副本；项目采用 Codex 归档约定时沿用，不无意义地叠加多层审计包。

把反馈分为：全局规则、页面内容、素材替换、图注字句、布局关系、删改合并。每条记录旧页与合并后新页的对应，避免页码变化后改错对象。明确原句照录，不以“更完整”的机构名或推断身份覆盖用户确认措辞。

全局字号、导航或页码修改要遍历所有受影响页；局部问题不借机改写其余已认可内容。拆页/合页后重新检查章节编号、图文对应、页码、动作顺序及备注引用。

## 脱敏是内容处理，不只是盖住预览

只有当前任务需要脱敏时启动此流程。先明确隐藏对象及允许保留项，例如某些姓名、单位、负责人、日期、邮件信息或照片人物。未知人物位置不可猜；必要时集中询问，继续处理不依赖该答案的页面。

采用与素材协调、足够不透明的色块，保留证据可读性。原始来源保留在私有工作区；对交付版本：

- 图像中的敏感区域应写入脱敏副本像素，替换嵌入图，而非仅放一个可移走的覆盖形状。
- 正文、表格、备注、替代文字和隐藏对象中的同一字段也要按范围检查；源PDF、邮件、原图、嵌入对象或外部链接不应以未脱敏形式留在可提取包内。
- 检查默认预览与PPTX资源包；若只能做展示遮挡而不能保证不可恢复，明确说明，不宣称完成安全脱敏。
- “截图必须保真”与脱敏并不冲突：仅遮指定区域，其他字形、布局和证据不重排。

不因一次比赛隐去导师，就默认以后所有PPT删除单位或遮挡所有合影；也不因照片公开就忽略当前明确要求。

## 两层检查

**结构检查**用于发现需要看的地方：页数、逻辑页序、尺寸、对象计数、显式字号、嵌入字体、图片关系、文件可导入性。脚本输出不等同于阅读效果，显式字体盘点也不等于解析了全部母版继承。

**视觉检查**直接查看最终文件的渲染：

| 层级 | 重点 |
|---|---|
| 整套 | 配色和组件一致；页序/板块合理；字号层级统一；素材不无意义重复 |
| 页面 | 标题完整；文字无溢出重叠；正文与导航留白；关键证据可辨 |
| 图组 | 比例、视口、间距、上下边界；人物与图表关键信息保留；图注归属正确 |
| 光学细节 | 实际字形顶底与重心；标志干净；同字号是否因字形/框边距显得失衡 |
| 事实 | 数字、单位、名称、个人/团队归属、已完成/接收等状态一致 |
| 最终交付 | 导出后仍可打开；字体可用；新增图片/证书真实存在；内部文件未混入 |

先用联系表看整套节奏，再看每个受影响页的完整尺寸和密集截图。全局改动覆盖所有内页；封面、长标题、叠瓦、证据裁剪和表格是重点。检查最终导出或重新导入版本，不只检查制作工具中的预览。

保持文字、原生表格等可编辑。若实现工具无法保留母版、动画或原生组件，先采用更适合的可用路径；确实无法完成时报告具体限制，不以全页图片或静态预览冒充原功能保留。

## 只有需要时检查音视频

不默认添加背景音乐、动画或自动翻页。用户要求时，记录每路媒体何时开始、是否循环、何时停止、是否跨页及是否有音轨；避免视频原声与背景音乐冲突。检查首尾黑帧、字幕遮挡、静音与音量、跳页后的状态。

静态渲染或XML属性不能证明自动播放、跨页循环和音轨控制正常。应在目标演示软件中实际试播；无法试播则明确“媒体播放尚未实测”。不要因为历史任务曾要求清空备注或静音视频而自动执行。

## 克制的交付

按用户要求交付必要的文件，并确认路径或下载链接有效。多种必要成果可同时提供单文件入口与ZIP；单一PPT不为凑齐格式而额外导出多套文件。

内部素材索引、QA、临时渲染、脚本及隐私原件留在工作区，除非用户需要，不加入交付包。说明已完成的变化与未验证事项；只有实际用目标软件打开/试播，才可以声称做过该项验证。
