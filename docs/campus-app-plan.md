# 求是·汇报：校园应用推进方案

“求是·汇报”为工作名，属于个人参赛作品，不代表浙江大学官方应用，不使用校标。以下赛程与提交要求依据用户提供的通知内容，报名及提交时再以赛事原文为准。

## 一、定位与参赛方向

建议主报**教育教学方向**：服务课程汇报、组会汇报和文献分享，将已有制作规范转化为学生可操作的汇报工作台。科研创新方向可作为应用场景补充；目前核心价值是材料组织、证据表达与规范制作，研究发现与实验设计仍由使用者负责。

目标用户是需要反复完成学术汇报、已有材料但缺少稳定制作流程的学生。首版验收目标：用户能完成一次“导入材料结构—确认内容—调整风格—修改单页—导出可编辑 PPTX”的完整操作，并现场复现。现有组会、社会实践和国奖 PPT 经历提供需求依据，尚不等于应用已有试点成效。

## 二、三个场景

| 场景 | 输入与输出 | 核心质量标准 |
|---|---|---|
| 课程汇报 | 课程任务、听众基础、知识材料、时长；输出问题导入、概念解释、例子与讨论及讲者备注 | 对应学习目标；术语首次解释；不把未讲授的内容当作听众已知 |
| 组会汇报 | 本轮问题、研究进展、图表、下一步计划；输出问题依据、方法、结果、讨论与待决策事项 | 原文结果、本人再分析和计划明确区分；单位、样本量、统计口径与图保持对应 |
| 文献分享 | 已阅读的论文内容、元数据、原图及阅读范围；输出科学问题、关键实验、证据解释、局限与讨论 | 一页一个命题；保留原图轴、标尺和图例；结论可定位到来源，不把摘要阅读写成全文核查 |

所有场景保留标题、正文、来源与备注的编辑能力。原始 Figure 保持图像身份，图下给出一句与证据对应的说明。

## 三、首版功能与分工

1. **模板适配。**读取用户 PPTX 的页面尺寸、主题色与可识别字体参数，展示提取结果供确认；结合可选 profile 形成页面。复杂母版、动画和特殊对象的完整保真不属于此首版承诺。用户本轮要求优先于模板，模板优先于默认规范。
2. **导航与主题。**可切换顶端横排、左侧竖排；内容区随导航重新分配，移动页面同步更新章节和页码。提供预设色与自定义主题色，检查文字对比和长章节名容纳；不改变原图颜色。
3. **来源追踪。**每页可关联题名、期刊或机构、年份、链接及备注中的 Figure／页码；区分原文、再分析和计划。页底仅期刊或机构名称可点击。应用检查字段完整性，来源是否支持具体结论仍须人工核对。
4. **局部修改与时长。**编辑当前页的标题、正文、布局、图注和备注，保留其他页面；可增删移页。逐页填写预计讲述秒数并汇总，与目标时长比较；不把文字计数直接当作真实讲述时间。
5. **AI 协作导入。**生成含场景、素材、页数、时长、来源及 JSON 格式的任务包；用户复制到 ChatGPT 或千问办公，将返回结构导入工作台再编辑。缺失字段、非法格式和不支持的内容应显示具体问题，不能静默替换成示例内容。

**首版采用本地浏览器静态应用，内容模型驱动预览与 PPTX 导出。**文字、导航和页码输出为原生对象；工程 JSON 可保存后续继续编辑。内置示例仅用合成材料或已核实的公开内容；私人科研材料、论文截图、字体及模板原件不进入公开仓库。AI 任务包发出前由用户选择具体内容。

ChatGPT／千问办公负责用户主动发起的内容梳理、提炼与修改；Qoder 和 ChatGPT 的开发能力用于实现、调试应用；工作台负责场景字段、风格参数、来源映射、局部修订和导出。首版不宣称已内置大模型，也不假定现有订阅包含 API 权益。与通用助手的区别应由这些可演示的操作和实测结果体现。

## 五、如何证明应用有用

设置三种基线：A 手工 PowerPoint；B 通用助手对话后人工排版；C 现有 Skill 配合助手。与本应用比较时，B、C 和应用使用同一助手与相同素材。六项任务为三个场景各两项：①依据素材新建 4—6 页；②在已认可版本上完成指定局部修改、导航和主题调整。固定要求，交错执行顺序；记录操作者与模型版本。

| 指标 | 测量办法 |
|---|---|
| 效率 | 从打开任务到获得满足要求的 PPTX；分别记录人工操作、模型等待和返工时间，报告各任务及中位数 |
| 来源准确 | 对照素材逐条核对论点、图与来源；统计正确对应数／应核对数，并单列无依据新增论点、错链和漏引 |
| 版式 | 打开最终 PPTX，按页计数裁切、重叠、字号层级、导航页码和图注错位；报告每十页缺陷数 |
| 可修改性 | 执行改标题、改双栏、替换图、移页四类操作；记录成功比例、耗时及其他页面的意外变化 |

目标是减少重复操作并维持来源和交付质量；具体改善幅度由数据决定。简短检查表与计时记录足够，汇总进入作品介绍，无需另交繁琐 QA 文件。小样本试用只支持本轮任务中的可用性判断。

## 下一轮重点

1. 用实际授权模板判断参数提取与页面效果，确定最需要保留的模板特征。
2. 选一段课程、组会或文献素材，完成真实汇报片段，检验来源和局部修改是否顺手。
3. 根据实操耗时与同学反馈，确定参赛主场景及最终作品名。
