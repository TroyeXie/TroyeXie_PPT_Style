# 社会实践图文总结册

把分散材料整理为有事实、有重点、图文协调且可直接提交的总结册。优先解决初稿的内容组织、真实素材选择和对齐关系，避免靠反复堆字、缩字号补救。

## 先确定当前任务

优先级：**本轮要求 > 最新确认文件与指定模板 > 明确选用的预设 > 本技能建议**。

- 新建：实读参考册、成果材料、照片及媒体清单，确认页数、尺寸和输出格式。先形成简短事实表与图文骨架，再制作。
- 续改：读取最新成品和可编辑源，记录本轮改动及必须保留部分。保留已确认的文字、数据、字体与图片，不从旧稿重建。
- 页数没有指定时，依材料和受众决定；本包的两页模板是可选起点，不是所有总结册的要求。

## 材料到页面

1. **确定事实口径。**对活动、调查、团队、报道和奖项记录来源、单位、状态及最新确认值。冲突按明确的最新授权来源解决，不取数字较大者。见[内容与证据](references/content-and-evidence.md)。
2. **选择能证明行动的图片。**实际查看照片，按活动场景选主图、辅助图及精确图注。问卷访谈用现场访谈照片，不能以材料整理场景代替。图片默认等比完整适配；需要裁剪时检查关键人物和现场信息。
3. **先精炼内容。**团队身份、指导者职务与专业、项目缘起、实际行动、成果最有信息价值。把活动类型和数量融入短段，避免重复人数条、口号条和同义统计。正式表达应由具体行动支撑。
4. **建立图文层级。**主标题、色底模块标题、普通正文、重点数字、图注、奖项构成清楚层级。大小变化与跨栏区域服务阅读顺序，不机械排成等宽双栏。
5. **共享对齐锚点。**图片与图注共享左右边界；同列的奖项卡、照片和图注也共享边界。校标以实际可见图形计算大小，两页尺寸一致，并与各自标题的视觉中心协调。见[视觉与两页预设](references/visual-and-preset.md)。

## 快速生成初稿

需要两页正式宣传风格时，用[合成示例](examples/brief.example.json)填写本轮精简内容；路径相对该JSON。准备有使用权限的正文/标题字体与真实图片，运行：

```bash
python -m pip install -r requirements.txt
python scripts/build_booklet.py examples/brief.example.json --font-body /path/to/body.ttf --font-title /path/to/title.ttf --output local-review/draft.pdf
```

已有依赖可跳过安装。将字体参数改为本机有权使用的TTF路径；命令帮助用`--help`，字段见[brief与工具](references/brief-and-tools.md)。脚本采用 A4 两页、沉稳红/金/暖白配色、非对称图文模块及获奖卡；会拒绝溢出，不静默缩字。它是可调整的排版源，其他尺寸和结构应改源文件。字体、校标和真实活动素材不随本包分发。图片占位仅用于合成示例，提交前换为真实授权素材或删除无材料模块。

标题字体从实际参考文件核对，不仅凭截图猜测。书法字体适用于局部主标题；其余字体按用户规定统一。缺少字体时明确说明，不能静默替换。无独立粗体的楷体可在本地有限描边，但须核查实际笔画、字腔和标点，不能假定设置 bold 就已生效。

## 精修与验证

读[局部修订与验收](references/revision-and-quality.md)。优先改可编辑源；只有成品PDF时，可在确认对象与文本编码后局部修订，避免覆盖成整页截图。

- 重点词组按完整语义加粗/着色，跨行末字也覆盖；前缀和标点不随意扩大强调范围。
- 文字、线条、色板、授权校标保持矢量；照片和报道截图仍是像素图，不声称整册所有内容均为矢量。
- 导出后运行只读预检，并实际看每一页和密集区域：

```bash
python scripts/preflight_pdf.py final.pdf --expected-pages 2 --render-dir local-review
```

预检只证明已实现的结构项，不代替视觉或事实审核。对局部精修，必要时比较修改区外的像素、原文字顺序、图片和链接。确认最终路径、页数与版本后再交付。

## 交付与复用范围

按需求提供最终PDF和可编辑源文件；用户明确需要Word时提供Word，不以PDF代替。QA、事实表、素材索引留在项目内部，默认不混入成品。保持原件可恢复，原位更新采用与风险相称的备份和最终读回核验。

公开技能只包含通用方法、参数化代码和合成示例。制作或读取权限不等于发布照片、校标、字体、采访、个人资料和内部材料的权限。发布技能需本轮明确授权；技能本身不隐含后续GitHub写入或安装授权。
