# 内容与证据

## 事实表应能解决的冲突

在项目内部记录“字段 / 值 / 单位 / 来源及页表位置 / 状态 / 本轮修订”。仅填影响版面和结论的内容，无需建立庞大审计包。

| 类型 | 需要区分的口径 |
|---|---|
| 团队 | 实际参加人数、教师/学生、专业、职务与排序；不能以通讯录全部条目代替实际名单 |
| 服务 | 场次、天数、户数、参与人数、服务人次、医院/单位数量；不能互换或重复相加 |
| 调研 | 发放/回收/有效问卷、访谈人数/次数/材料份数、团队/个人报告篇数 |
| 媒体 | 发布条目、原创作品、转发、视频；国家/省级分类必须有明确登记或机构依据 |
| 奖项 | 活动名称、作品/案例名称、奖项、入选状态、指导教师奖与团队奖分别核实 |

用户指定PPT数据为准时，实际读相应页；不要沿用旧工作簿或从旧PDF回填。最新明确修订优先于旧记录；实质歧义集中确认，其余独立工作继续。

媒体优先访问原报道页面，以真实平台标识、题名和发布内容制作截图。国家级优先是展示顺序，不是推断分级依据。总数与各级数量独立核对；同一URL/转载怎么计数应按本轮明确口径处理，不能为凑数自行去重或合并。没有网页访问成功就不声称核实了网页。

## 从材料压缩为页面

一段正文通常只承担一个目的：背景与差异、行动与数量、结果与意义。先保留具体名词、动作、数字和单位，再删除重复修饰。活动统计可写成“开展若干场服务：义诊、送医入户、科普、课堂与培训……”，用少量重点色突出数量和类型。

研究模块说明收集了什么、聚焦什么、形成什么成果；把“完成团队调研报告1篇”等短结论视作完整单元，尽量不拆成两行或留下孤字。正文长度超限先精炼，不以压字号替代编辑。

模块标题可采用“行动 + 服务对象/价值”并配短而对仗的主题词。正式不等于空泛：价值表达仍须与真实行动相称，不无依据增加“首支”“首创”“国家示范”等身份。标题不要机械重复正文中的统计。

指导者信息优先使用本轮确认的职务与专业，按用户给定顺序展示。领导寄语优先提炼已提供原文；合并转述不加直接引号，不凭合影推断姓名身份或发言内容。

## 媒体与成果的呈现

媒体叠瓦可体现传播广度：前排放主流媒体，数量有限但主要标识与题名可读。不要为了“报道多”把截图压到无法辨认，也不要制造仿真报道页面。

获奖卡把**奖项名称**作为主视觉，活动名称放小一级；可按已确认口径精简长活动名，不把“创新案例”自行改称某等级奖。卡片文字不超过可容纳行数；与邻近照片列共用边界，保留稳定间距。

成品不自动加入流程性注释、样本口径防御句、制作说明或重复页眉标签。必要限制在关联内容处简明说明，其余口径核查留在内部。对无依据或缺失的事实不填造。

## 公开包与项目素材

技能示例用合成团队、人物代称与示意内容。不要上传本次附件、个人学号电话、内部访谈、真实活动照片、报道截图、字体二进制、原校标或个人绝对路径。即使成品已公开，也不自动意味着所有素材均可再分发。
