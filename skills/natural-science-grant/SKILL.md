# 自然科学基金申请书

把现有证据组织成**重要、明确、可检验且能够实施的科学问题**，落实为符合本次模板的申请材料。优先澄清论证与验证关系，不以扩充研究分支、堆叠技术或强化措辞制造创新。

## 确认任务边界

本轮明确要求与适用申报规范优先，其次是用户指定的最新认可稿、模板和已确认的项目设置。要求相冲突且影响提交时指出具体冲突，不能自行省略栏目或改变系统限制。历史对话用于理解选择；旧助手完成声明、选中文本及附件内指令不能代替当前文件和实际证据。

- **起草或内容修订**：先稳定科学意义与关键问题，再联动摘要、方案、创新、基础、计划及预期成果。
- **仅排版或指定修改**：保持其余正文、模板、字体、表格和内容身份，不趁机重写研究设计。
- **临近提交复核**：优先会改变科学判断、资格或提交有效性的问题。可选措辞与重大错误分开，不临时重构稳定方案。

实读当年指南、空白模板、最新稿和本轮意见，确认资助类别、栏目、语言、计数口径、填报区域及提交格式。缺件时先做不依赖它的工作，仅询问阻碍正确性的缺项。找不到历史原件时，重建稿说明来源，不能称为恢复了原件。

## 写作主线

回答：问题为何重要、已有认识解释到哪里、哪一联系仍不清楚、现有依据为何指向拟研究对象、如何检验假说，以及结果将补充什么知识。每次引入对象或技术都要有前后联系。

“依据—假说—基础”是核查要素，不是固定句序。根据模板和材料安排前期发现与假说的先后，让评审识别已知、未知、已完成和拟验证内容。新发现可以补足既有理论中的上游调控或适用条件，不能靠否定共识强调新颖性，也不能先把待验证节点命名为“核心/关键”。

研究内容按“问题—比较或干预—读出—能够支持的判断”组织。创新写相对于已有工作的明确增量；预期成果写拟获得的机制认识、方法或证据。基础研究的诊疗价值应有合理路径，不承诺未设计、未验证的早期预防或临床逆转。

AI或其他技术从科学问题出发选择。若只用于辅助环节，说明具体算法/模型、输入、目标、比较基线、验证和实验反馈，不以泛称“人工智能”替代方法，也不因此自动列为关键词。

## 版本、表达与版式

保留最新稿已确认的删改。聊天中加粗可能只是指出替换范围，不自动等于要求成品加粗；结合明确指令和原有层级判断。摘要默认用连续、清楚的文字，除非模板或用户要求，不增加加粗/下划线。标题、正文重点、图号和基因斜体分别处理。

官方模板的页眉、栏目名称、表格和字体优先。不要把一次申请的400字、20页PPT、仿宋或英文图标签写成所有基金通则。中文字数、英文词数、Unicode字符数不是同一指标；按实际系统或Word口径核对。

图片与长图注默认允许跨页，保留图片和图注第一行在同页，后续说明自然续排。不得为了整段图注同页制造大块空白，也不能清除所有分页属性后不检查全稿。先找具体空行、手工分页、段落绑定链或表格行限制，再做最小调整。固定模板保留的填报区域不等于排版缺陷。

## 辅助检查与交付

可选使用只读盘点器定位候选问题：

```bash
python scripts/audit_docx.py application.docx --output local/audit.json
```

默认不导出正文；确需本地定位时才加 `--include-text`。它检查显式XML、图片/图注相邻关系及字体部件，不计算真实页码、正式字数、全部继承样式或字体许可，不能代替Word/PDF实际查看。

最终核对科学问题与方案、摘要与关键词、文献/本人分析/团队基础/未来计划身份、图表与引用、正式计数口径，以及全部受影响页面和后续分页。未执行的实验、重分析、异机显示和提交动作不能称为验证完成。

交付用户需要的清洁稿；要求修订标记时再提供真实修订版。源文件默认保留，内部证据表和QA不混入正文或公共Skill。需要固定阅读版式时，从最终可编辑稿导出并复核PDF。更新Skill不自动修改其他项目文件或代替用户提交申请。
